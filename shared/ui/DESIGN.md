# Desktop UI/UX 迭代规范

版本：1.2 · 更新时间：2026-10-20T16:05:08+08:00

适用范围：Windows、macOS、Linux Desktop 的视觉组件、页面布局和交互呈现。当前 UI v2 在 `dev-ui` 的 macOS、Linux、Windows 均有开发候选；本规范不表示目标平台编译、媒体或视觉验收已经完成。

## 1. 唯一来源与变更边界

- 本文维护长期约束；[README](README.md) 的尺寸表及 `src/v2.rs` 的 `Metrics`、`Palette` 维护当前数值和实现。不要在多份评审稿重复维护 token 表。
- 每轮记录设计稿版本、页面/状态、代码分支与基线。Frog S2 是本轮参考；旧流程图只解释流程，不能覆盖较新的主界面配色。生成图、HTML 和原生实现分别标明。
- 设计意图决定目标，实际代码决定已交付能力；两者不一致必须列差异，不能默默以代码替代设计，也不能将图中能力当成已实现。
- 三端共享视觉语言，平台拥有选源、权限、窗口外壳、媒体和连接生命周期。不为统一截图绕开系统 Portal 或伪造平台能力。
- 本轮固定契约：观看从设备列表进入；共享位于本机上下文；发布/观看互斥；返回列表不隐式停止播放；LIVE 及红色 `#D92D20` 保留；不新增快捷键。
- 发现、连接、可观看、播放是不同状态。用户明确关闭 Nearby 表示完整 LAN 离线，停止观看/共享并清理连接；单独 mDNS Lost 不具有这个含义。视觉组件不负责资源清理。

## 2. 布局与间距契约

| 层级 | 责任与检查 |
| --- | --- |
| 窗口外壳 | 平台处理标题栏、系统按钮、安全区域与逻辑内容尺寸；不得在页面再补一次系统 inset。 |
| 页面 | 唯一负责页头、页脚和工作区外边距；按完整内容宽度选 compact/wide，嵌套卡片不得再次计算断点。 |
| 卡片 | 负责边框到内容的内边距；内容区先扣除内边距，再分配子项。卡片间距离由父容器负责。 |
| 行/组件 | 明确图标、文字、状态、动作四个槽位；动作按真实文字测量预留，名称最后截断。 |
| 弹层 | 使用共享 dialog frame；统一 24pt 内边距，标题、正文和操作区对齐。小视口下限制宽高并保留内容滚动及操作可达。 |

- 页面不得靠连续 `add_space`、负偏移或扩大空白遮盖组件错误。新间距优先归入 `Metrics` 或拥有该布局的组件；单页例外必须写明原因。
- 同一种边距只扣一次。核对窗口→页面→卡片→内容四层边界，不能把设计稿外边距同时放在父、子容器。
- egui 以逻辑点计量；截图物理像素必须除以实际 pixels-per-point 后比较，不把 Retina 截图尺寸直接当布局值。
- 校验实际绘制的文字与图标，不只检查 `Response.rect`。`Ui::place` 可使文字 galley 在左对齐占位框内继续居中。需要固定左边界时使用明确的子布局，按钮内容使用明确居中布局。
- 同一行文字基线和图标视觉中心应一致；不得以某一个短名字或某一种字体为标准手调偏移。
- 高度由内容、上下 inset 和必要的最小高度推导。440pt 等上限不是必须填满的固定高度；空状态可以有明确的展示高度，不让一行设备撑出不必要空白。
- 首选操作区先从有限视口中预留，再布局可滚动内容。禁止把整个共享页放入外层长滚动区，导致开始/停止按钮随列表滚走。
- 少量固定设置应在标准面板一次展示完整，采用稳定宽高并适配最小窗口；滚动只为小视口或长错误信息兜底，不以滚动掩盖松散布局。导出日志属于常规设置，不依赖开发者模式。当前面板内容宽上限480pt、正文常规256pt，开发者模式按平台内容使用312pt或368pt，保留24pt外框内边距与固定关闭区，小窗口可缩短正文并滚动。
- 应用自有共享来源列表独立滚动，使用浮动滚动条：滚动/悬停交互时可见、离开后淡出，并支持拖动。刷新、编码/声音设置和开始/停止操作不得放进该列表或其父滚动区；长错误信息可在下方独立区域滚动。macOS/Wayland系统选源保持系统滚动行为。其他区域隐藏滚动条不等于禁止滚动。鼠标、触控板以及现有焦点导航必须能到达末项；焦点、选中项和展开的错误内容不能被裁切。

## 3. 组件和状态契约

- 通用颜色、字号角色、边框、圆角、间距和交互态归入共享库；平台页面只组合组件并响应事件，不复制一套按钮或弹层样式。
- 新组件至少说明：输入、输出事件、最小可用尺寸、溢出策略，以及 normal/hover/pressed/disabled/selected/focus 中适用的状态。组件不得持有媒体或连接对象。
- 一个设备行中的详情与观看命中区域互不重叠；装饰与文字不得吞掉动作点击。按钮命中范围至少 40pt，内容居中；长文案优先测量，不能只给固定宽度。
- 名称支持长中文、英文、无空格串；必要时截断，但详情可取得全文。状态与主要动作保持可读，不用颜色单独表达失败或选中。
- 浅色、深色、跟随系统共用布局；主次文字分层，禁用与辅助文字仍应可辨。系统主题切换不得改变播放器专有深色舞台或 LIVE 颜色。
- 明确空列表、连接中、连接失败、可观看、播放中、来源失效和权限拒绝的用户动作。状态文案来源于实际 snapshot，不通过改文案掩盖未确定的连接语义。

## 4. 每轮必做，按影响范围扩展

1. **开始前**：列本轮页面/组件、参考版本和保持不变的产品契约；读取现有 token 与相关回归。不要先逐页修数字。
2. **实现时**：组件缺陷在共享组件修；页面组合缺陷在页面修。可稳定复现的错位/点击/溢出补针对性回归，验证撤去修复时会失败；纯审美调整无需堆快照测试。
3. **自动检查**：运行受影响组件的布局/交互测试及格式检查；新增测试进入现有 Shared UI CI。影响共享库时核对平台消费者与 workflow 路径过滤，目标平台编译按现有 CI 分工执行。
4. **原生检查**：启动本次构建的目标应用，记录路径、源码状态、窗口逻辑尺寸、缩放和主题；避免多个旧实例混用。用真实窗口截图检查实际对齐和留白，再实际操作受影响控件。HTML 或组件目录不能替代原生页面。
5. **交付时**：逐项写已检查、未检查与原因，给出截图/日志路径；未检查的项目保留待验，不以“测试全绿”宣称视觉还原完成。用户审美认可与功能真机测试单独记录。

### 检查矩阵

优先验收常规桌面窗口。用户于2026-10-20明确：窄窗专项问题默认P2，除明显遮挡、关键操作不可达或状态完全丢失外，不作为本轮阻塞项；已有便宜回归保留，不扩展窄窗专项适配。组件 token、断点、主题或页面 shell 改动时，按风险使用下列矩阵。可用 fixture 复用多项组合，不要求每次跑无关页面的笛卡尔积。

| 维度 | 必须覆盖的边界 |
| --- | --- |
| 尺寸 | 当前最小支持窗口、常规窗口、最大化；涉及断点时测试断点前后（当前 919/920pt）。 |
| 缩放 | 受影响平台可用的普通和高 DPI；模拟 pixels-per-point 仅为布局证据，不能冒充另一台设备。 |
| 内容 | 0、1、多行及溢出列表（目录可用 40 行）；长中文/英文名、无空格串、长错误提示。 |
| 主题 | 浅色、深色；主题改动需检查跟随系统与弹层，不只检查主界面。 |
| 页面 | 本机/设备列表、共享选源和固定操作、设置/详情/确认弹层、受影响的播放与返回路径。 |
| 操作 | 点击命中、禁用、选中、焦点、滚动到底、缩放后仍可操作；已有键盘可达性不等于新增快捷键。 |

组件矩形与绘制位置、命中隔离、有限高度、长列表按钮可达可以自动测试。视觉密度、字体观感、原生窗口外壳与系统弹窗必须人工/原生检查。没有目标系统时明确待验，不能用 Mac 通过代替 Windows/Linux 通过。

## 5. 不得标记为完成的情况

- 文字或图标明显偏移、内容覆盖/裁切、操作被列表挤出、滚动末项不可达、弹层按钮不可达。
- 改了共享组件却仅看组件示例，没有检查本批迁移的平台页面。
- 只知道占位矩形正确，没有查看实际绘制内容；只编译成功，没有运行本次构建。
- 以视觉调整名义改变发现/媒体/导航契约，或把未获批准的新能力放进正式界面。

这些问题应在当前授权范围内修完；环境无法验证时交付为候选并列出缺口，不反复要求用户发现明显布局错误。不得以本规范擅自扩大提交、合并、跨平台迁移或产品功能授权。

## 9. 关闭、停止与恢复动作（2026-10-11）

- 关闭弹层是中性操作：设置、设备详情、关闭附近设备确认框统一使用标题栏右侧的 `×`，图标使用主文本色、边框与悬停态，命中区域至少40×40pt，提供具体的可访问名称。设置/详情不再保留底部重复“关闭”；设置即时生效。不能用红色暗示关闭弹层会停止媒体。
- 停止观看、停止共享及关闭附近设备使用 `ActionTone::Danger`，保留完整动词/对象，不只依赖颜色。浅色危险前景 `#AE2B24`，深色 `#FFB0A9`，搭配低强度背景；遵循 Frog S2 的危险动作方向。LIVE 的文字和 `#D92D20` 不变。
- 附近设备页脚写“开启附近设备／关闭附近设备”，避免孤立的“开启／关闭”；状态文字可截断并悬停查看，不能挤走操作。确认与真实开关行为由原有平台逻辑负责。
- 长错误与长说明放进有限高度的内容区，先预留底部恢复动作，再渲染正文。“停止并返回”、开始/停止共享、弹层底部动作不能被正文顶出视口。
- 播放器紧凑宽度不足时可用明确的短标签（英文 Stop），常规宽度使用完整标签（Stop watching）；仍需保留音量、信息与全屏入口。返回列表仅导航，不能隐式停止播放。
- 新增动作角色只属于 opt-in v2；迁移平台逐个验证，不能把 Mac 检查视为三端完成。

## 10. 状态语义与动作层级（2026-10-11）

- 颜色从平台的真实状态投影得出，不从翻译文字推断。`StatusTone` 统一中性、活动、等待、服务正常、警告与失败；浅深色值只维护在 `Palette`。
- Nearby 正常扫描使用绿色稳定圆点。开启/关闭等待中使用进度提示；关闭/睡眠暂停为中性；发现失败为错误；扫描仍运行但连接服务不可用显示警告。绿色不证明已经发现、验证或连接了任何远端。
- 设备“已发现”保持中性；当前三端“已连接”和“可观看”均使用强调色，以明确文案区分，观看权限必须另外核对有效路由。实际观看中的设备行轻度突出。只有媒体 phase=Watching 且 peer/owner 匹配才可标“正在观看”；准备或播放失败不能被可观看目录覆盖。mDNS Lost 不隐藏仍有效的观看路由。
- 本机媒体空闲、准备、活动与失败采用相同语义。返回播放器是导航；不能因进入播放器页就宣称已播放。
- 提示使用可换行的 `notice`（指示符＋文字），失败用错误色、部分能力不可用用警告色；普通说明保持中性。危险操作色与错误状态色可以同族，但含义靠文字明确。禁止在页面写死浅色错误红。
- `Primary` 用浅强调底和边框承载“开始共享／观看”；选择来源、返回、取消用中性动作，停止用Danger。禁用条件仍由平台决定。扫描不加持续闪烁，进度只用于等待中的操作。
- 当前状态完整矩阵仍需区分离线回归与真实设备；不以假设备或样式预览宣称媒体已验证。

## 11. 文案精简（2026-10-11）

- 常驻文案只保留任务名称、真实状态、选择结果、必要限制和可执行的错误恢复。按钮已明确下一步时，不再附“请选择／准备就绪／可以开始”等同义提示。
- 同页不叠加同义标题，不解释系统选择器、服务返回或资源释放等实现细节；准备/停止用简短状态。一般说明不得包装成常驻警告框。
- 设备详情每个事实只说一次；当前运行ID的补充说明可放悬停。日志保存说明放导出入口悬停，正常设置页不反复提示。
- 不为精简而删除权限要求、系统声音支持范围、失败原因或停止后果；发现/连接/可观看/播放仍须区分。中英文一起修改。


## 12. 播放状态居中与预览构建（2026-10-11）

- 播放区域等待/停止提示以完整内容块（spinner、间距、文字）居中，不能仅横向对齐文字；回归应核对实际绘制矩形，而非只核对输入的区域坐标。
- 交付用户进行真机测试的本地版本必须使用优化构建，默认与CI相同的release profile；未优化debug仅用于调试或明确标注的纯视觉检查，不交付为真机测试版。交付前核对实际运行二进制，记录源码状态、构建命令/profile和SHA-256；自定义优化profile必须说明与release的差异，局部优化dev不能冒充正式release。
- 性能探针采用实际帧尺寸、像素格式和alpha；区分局部耗时、媒体PTS间隔与端到端延迟。修正不具代表性的测量时保留更正，不让旧数字继续作为结论依据。

## 2026-10-19 第二版原型覆盖规则

- 播放器是独立舞台，返回 Nearby 不停止播放；不得叠加发现页脚或把视频嵌在普通页面卡片内。
- 黑色画面区域与主题色64pt工具栏分离，LIVE 保持原红色；等待只显示居中转圈及辅助功能标签，不显示“正在缓冲”。
- 设置中的日志导出一直可见；日志窗口关闭返回设置，导出/打开目录使用真实平台动作。
- 内嵌 Noto Sans SC，默认 Regular 400。字体文件自带的默认 Thin 100 不得作为界面默认字重；标题与正文层级通过明确字重、字号和颜色形成。
- 开始共享前，当前来源必须与屏幕/窗口选项一致。取消系统选源保留之前选择，不猜测用户授权了新来源。共享时禁用音频编辑不等于将其显示为关闭。

字体层级：正文400、主要操作500、标题/设备名称600；`strong()`仅代表颜色强调，不能代替明确的字重。按钮测量与绘制必须采用相同字体/字号/字重。品牌PNG保持原色和比例，不能用通用设备图标替代Logo。

## 组件迁移检查补充

- 页头和播放器几何由 shared-ui 提供，平台只保留状态投影与命令；不能直接搬运原型示例设备或假成功状态。
- 窄设置行使用上下布局，禁止依赖文字截断来隐藏操作按钮；来源项保持48pt高度和完整名称提示。
- 工具栏布局预留必须匹配实际控件组合；v2 音量区域148pt，不能沿用旧组件132pt。
- 平台页面回归需覆盖长来源列表下启动按钮可点击、返回列表不停止播放、日志导出不依赖开发者模式、来源类型与实际启动一致。
- 主机侧无窗口的 egui 测试验证几何和响应，不替代目标平台截图、高 DPI 或实际媒体测试。

## 2026-10-24 设备状态与动作验收补充

- 当前播放高亮只用于实际 Watching/Viewing。准备、停止仍可返回播放器，但不提前显示为正在播放。
- 新观看需要可用路由、空闲媒体槽和 LAN 接纳权限；单独发现/连接成功、匿名入站连接数量均不能替代可用路由。
- 用户关闭 Nearby 的命令成功入队后，UI 应立即停止接受新观看/共享，不能等到下一份后台快照才禁用。命令入队失败不应假装正在关闭；后台确认清理完成后恢复开启入口。
- 详情与已有播放器的返回操作不属于新媒体准入，不因新观看被禁用而一并隐藏。
- `v2_catalog` 的每行是独立视觉样例，不是同一时刻真实媒体快照；它覆盖浅深主题、九种设备状态、关闭等待与媒体忙时的动作。真正的权限由平台实际页面点击回归和 shared/lan-state 测试共同验证。
- “布局不拥有媒体会话”的进一步专项审查已按用户要求排到 GPU 升级后；本批不修改面板、会话所有权或现有返回行为。
