# moqcast-ui 更新记录

## 0.2.0（开发候选，尚未发布）

- 新增 opt-in v2 主题、语义状态、设备行、本机卡片、弹层及设置行。
- 内嵌品牌图像，明确字体默认字重及控件文字测量。
- 新增完整播放器工作区布局、主题工具栏、音量/播放信息与失败恢复呈现。
- Mac、Linux、Windows 候选复用 v2 页头与播放器布局；旧组件入口保留供未迁移消费者。
- 新增48pt来源行、窄设置行堆叠和实际音量控件宽度契约，长来源列表保留固定启动/停止区。
- 三端消费者锁文件同步组件版本；应用发行版本不变，无网络协议或 MoQ API 变化。

迁移：选择 v2 的平台调用 `v2::install` 并组合 v2 组件；播放器使用 `v2::player_rects`。平台继续负责实际命令、权限和生命周期。旧入口不自动切换视觉样式。验证状态见工作区对应迭代记录，不以此更新记录代表真机验收。
